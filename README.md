# MomoTalk

一个《蔚蓝档案》风格的同人聊天界面，可以和自己喜欢的角色对话。

## 功能
- 与蔚蓝档案角色进行 AI 对话
- 支持多个角色人设（星野、白子、芹香、野宫、绫音等）
- 支持自定义角色
- 支持毛玻璃外观
- 数据本地保存，可导出/导入 JSON
- 支持多家 AI 服务商 API Key

## 如何 fork 并部署自己的副本
1. 点击本仓库右上角的 **Fork** 按钮。
2. 进入你自己 fork 后的仓库，点击 **Settings** → 左侧栏 **Pages**。
3. Source 选 **Deploy from a branch**，Branch 选 **main**，文件夹选 **/(root)**，点 **Save**。
4. 等 1-2 分钟，访问：`https://你的用户名.github.io/MomoTalk/`
5. 打开页面后，在设置里填入你自己的 API Key。

## 如何申请各服务商的 API Key
- **OpenAI**：去 platform.openai.com 注册，在 API Keys 页面创建。
- **Claude**：去 console.anthropic.com 注册，创建 API Key。
- **Gemini**：去 aistudio.google.com 注册，创建 API Key。
- **DeepSeek**：去 platform.deepseek.com 注册，创建 API Key。

⚠️ 注意：API Key 只保存在你自己的浏览器里，不要提交到 GitHub。
